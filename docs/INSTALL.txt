DIVINITY by TRIPLE SEVEN AUDIO
==============================
Hybrid synthesizer - VST3 / AU / Standalone - macOS (Apple Silicon + Intel) and Windows x64
https://triplesevenaudio.com

WHAT'S IN THIS ZIP
  mac/      DIVINITY.vst3, DIVINITY.component (AU), DIVINITY.app (standalone)
  windows/  DIVINITY.vst3, DIVINITY.exe (standalone)


MAC INSTALL
-----------
1. Copy DIVINITY.vst3 to      ~/Library/Audio/Plug-Ins/VST3/
   Copy DIVINITY.component to ~/Library/Audio/Plug-Ins/Components/
   (In Finder: Go > Go to Folder... and paste the path.)
2. The build isn't signed yet, so macOS will block it the first time.
   Open Terminal and paste this once:

   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/DIVINITY.vst3 ~/Library/Audio/Plug-Ins/Components/DIVINITY.component

3. Open your DAW and rescan plugins (see below).
   Standalone: drag DIVINITY.app into Applications, then run the same
   xattr command on it if macOS says it's damaged.


WINDOWS INSTALL
---------------
1. Copy the whole DIVINITY.vst3 folder to
   C:\Program Files\Common Files\VST3\
2. Open your DAW and rescan plugins.
   If Windows SmartScreen warns about DIVINITY.exe: More info > Run anyway.


RESCAN IN YOUR DAW
------------------
Ableton Live  Settings > Plug-Ins > Rescan (hold Alt/Option for a full rescan)
FL Studio     Options > Manage plugins > Find more plugins
Logic Pro     Settings > Plug-in Manager > Reset & Rescan Selection (AU)
Bitwig        Settings > Locations > Rescan
Studio One    Options > Locations > VST Plug-ins > Reset Blocklist, then restart


NEW IN 1.1.0
- New teal skin with the exact DIVINITY / TRIPLE SEVEN AUDIO artwork and the barbed-frown Guardian Angel. Night mode = the same skin inverted.
- Opens bigger (125 %). Pick another size in the menu and DIVINITY remembers it.
- MIDI mapping: click the MIDI button (next to HIDE ANGEL), click any knob, move a knob/fader on your controller. Each mapped knob shows its CC. Click MIDI again to finish. Mappings are saved for every DIVINITY instance; menu > "Clear all MIDI controller mappings" resets them. (Right-click a knob > MIDI learn still works too.)
- Every factory sound re-voiced warmer and thicker.
- 80 new presets: WAVE, TRAP, TECHNO, DUBSTEP, GARAGE, DARK GARAGE, DNB, CINEMATIC (10 each, 351 total).

NEW IN 1.0.0
- New light "porcelain" skin + NIGHT MODE toggle (moon icon, top right, or menu > Night mode). Your choice is remembered.
- Drag modulation: grab the four-arrow handle next to an LFO / ENV / STEP / RANDOM title and drop it on any knob.
- Draw LFOs: click and draw on the LFO display (shape switches to Custom).
- Curve envelopes: drag up/down on an envelope segment to bend it, double-click to straighten.
- Distortion: Fuzz, Diode, Overdrive, Tape, Half Rectify, Crunch, Square Fuzz added.
- Multiband: move the Low/High splits and set Gain, Down Thr/Ratio, Up Thr/Ratio per band.
- Bigger default window.

NEW IN 0.8.0
------------
- WARP on every oscillator: Sync (hard sync), FM, AM, Bend +/-, PWM,
  Phase Dist and Mirror, with a WARP amount knob you can modulate.
  Sync / FM / AM use another oscillator as the source (even one that's
  switched off).
- Import your own wavetables: drag a WAV / AIFF / FLAC onto an oscillator
  (Serum / Vital tables work). Saved with your session and presets.
- MIDI learn: right-click any knob > MIDI learn, move a knob on your
  controller. Right-click > Forget to remove it.
- MPE: gear menu > MPE (per-note bend, pressure and slide for Roli,
  Linnstrument, Push 3, Osmose...).
- Quality: gear menu > Quality: Eco / Standard / HQ (2x oversampled), plus
  "Always HQ when rendering" for clean bounces.


NEW IN 0.7.3
------------
- Preset bank redesigned for variety. The 777 presets used to cycle
  through ~10 core sounds per category (so every ~10th bass was the same
  bass with different FX). Now every preset picks its own source,
  movement, filter, envelope and effects, and the bank was chosen from a
  much larger pool by measuring the audio: no two presets in a category
  sound like copies of each other.
- Same names for the headline presets (Abyss Reese, Viral 808, ...),
  same categories, same counts, still loudness-matched.
- The limiter now has a hard ceiling (it could overshoot by a hair).

QUICK START
-----------
CREATE   oscillators A-D, sub, noise, sampler, filters, envelopes, LFOs, 8 macros
EFFECTS  16-effect rack - drag to reorder, click a dot to switch on
PLAY     arpeggiator, macros, keyboard
BROWSER  777 presets by category, search, favourites
SOUL     drag the emotion pad; hit DIVINE INTERVENTION
LAB      modulation matrix, deep settings, GLOBAL (voices, drift, engine)
Guardian Angel (right side): ask questions or describe a sound to build.

Every control: hover for help, double-click to reset, shift-drag for fine,
right-click to type a value. Undo/redo: Cmd/Ctrl+Z, Cmd/Ctrl+Shift+Z.
